# video-parser

Telegram-бот для автора контента про нейросети:

- **🔥 Подборка** — находит свежие залетающие ролики из TikTok и Instagram Reels по вашим темам
  (хэштеги и поисковые запросы), ранжирует их по скорости набора просмотров, вовлечённости и
  отрыву от числа подписчиков автора. Уже присланные ролики не повторяются. Может приходить сама каждый день.
- **📊 Разбор аккаунта** — присылаете ссылку на профиль TikTok или Instagram. Бот собирает последние
  ролики, считает медиану просмотров, находит залетевшие (×2 к медиане и выше), скачивает их, вырезает
  кадры (хук в первые секунды и дальше по ролику), берёт расшифровку речи и отдаёт всё нейросети.
  Разбор приходит **PDF-файлом** (в чате — только короткая выжимка и стоимость): статистика, кадры хуков,
  почему каждый ролик зашёл, **как сделать похожий без своего лица** — по шагам через Claude, Gemini и
  простой монтаж в CapCut, без Blender и After Effects, — готовый промпт для Claude/Gemini на самую сложную
  часть, что улучшить, 3 главных вывода по аккаунту и 3 идеи роликов.
- **Разбор одного ролика** — ссылка на конкретное видео или кнопка «🧠 Почему залетело» под роликом из подборки.

Данные собирает [Apify](https://apify.com), разбирает и расшифровывает речь нейросеть через
[Polza.ai](https://polza.ai) (по умолчанию Claude Sonnet 5.5).

## Что нужно

| Что | Где взять |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | создать бота у [@BotFather](https://t.me/BotFather) командой `/newbot` |
| `APIFY_TOKEN` | [console.apify.com → Settings → Integrations](https://console.apify.com/settings/integrations) |
| `POLZA_API_KEY` | [polza.ai → API-ключи](https://polza.ai/dashboard/api-keys), на балансе должны быть деньги |
| `ALLOWED_USER_IDS` | ваш Telegram ID — бот сам пришлёт его на `/start`, пока список пуст |
| Python 3.11+ и ffmpeg | см. ниже |

Бот отвечает только пользователям из `ALLOWED_USER_IDS`, чтобы посторонние не тратили ваши деньги на Apify и Polza.

## Запуск на своём компьютере

Бот работает, пока запущен на компьютере. Сервер не нужен: бот сам опрашивает Telegram.

### 1. Скачать код через git

Нужен Git: на Windows — `winget install --id Git.Git -e` (потом открыть терминал заново), на macOS — `brew install git`.

```bash
git clone -b claude/amazing-allen-odgb9c https://github.com/optimazer3/video-parser.git
```

### 2. Установить Python и ffmpeg

**Windows** — поставить Python 3.12 с [python.org](https://www.python.org/downloads/) (в установщике
отметить «Add python.exe to PATH»), затем в PowerShell:

```powershell
winget install --id Gyan.FFmpeg -e
```

После установки ffmpeg закройте и снова откройте PowerShell.

**macOS**:

```bash
brew install python ffmpeg
```

### 3. Установить зависимости и создать `.env`

- **Windows** — дважды щёлкнуть `setup.bat`.
- **macOS / Linux** — в терминале в папке проекта: `./setup.sh`

Скрипт создаст окружение `.venv`, поставит зависимости, скопирует `.env.example` в `.env`
и проверит, что установлен ffmpeg. Запускать повторно безопасно: существующий `.env` он не трогает.

В `.env` вписать `TELEGRAM_BOT_TOKEN`, `APIFY_TOKEN`, `POLZA_API_KEY`. `ALLOWED_USER_IDS` пока оставить пустым.

### 4. Запустить

- **Windows** — дважды щёлкнуть `start.bat`.
- **macOS / Linux** — `./start.sh`

Напишите боту `/start` — он ответит вашим Telegram ID. Впишите его в `ALLOWED_USER_IDS` в `.env`,
остановите бота (Ctrl+C или закройте окно) и запустите снова.

### Обновление через git

Остановите бота (Ctrl+C) и в папке проекта выполните `.\update.bat` (macOS / Linux — `./update.sh`).
Скрипт сделает `git pull` и обновит библиотеки. Потом запустите бота снова. `.env` и база с темами
и кэшем (`data/`) в git не хранятся, обновление их не трогает.

Если код раньше скачивали ZIP-архивом, подключите ту же папку к git один раз (в терминале, в папке проекта):

```bash
git init
git remote add origin https://github.com/optimazer3/video-parser.git
git fetch origin claude/amazing-allen-odgb9c
git checkout -f -B claude/amazing-allen-odgb9c --track origin/claude/amazing-allen-odgb9c
```

После этого `git status` должен показать «nothing to commit»: `.env`, `.venv` и `data/` останутся на месте.

### Если Telegram или Instagram заблокированы

Если при запуске бот пишет «Не удаётся подключиться к Telegram», значит, Telegram недоступен у вашего
провайдера. То же касается Instagram: видео Reels бот скачивает со своего компьютера. Варианты:

1. Включить VPN **на весь компьютер** (режим TUN / «системный», а не только расширение в браузере).
2. Или прописать в `.env` локальный прокси вашего VPN-клиента — его адрес есть в настройках клиента
   («локальный прокси», «SOCKS5 порт», «mixed port»):

   ```
   PROXY=socks5://127.0.0.1:10808
   ```

   Через прокси пойдут Telegram и скачивание роликов; запросы к Polza и Apify идут напрямую.

## Команды

- `/feed` или кнопка «🔥 Подборка» — подборка роликов
- `/topics` или кнопка «⚙️ Темы» — темы подборки с кнопками ❌ (удалить) и ➕ (добавить)
  - `/topics + #sora, нейросети для монтажа` — добавить к текущим
  - `/topics - #sora` — удалить
  - `/topics #нейросети, #chatgpt` — заменить весь список; `/topics reset` — по умолчанию
  - с `#` — хэштег, без — поисковый запрос; рядом с темами бот показывает, во сколько обойдётся подборка
- `/model` — какая нейросеть разбирает ролики: текущая модель, цена разбора, кнопки с вариантами
  и переключатель «🎞 Видео целиком»; `/model provider/name` — любая модель из каталога Polza,
  `/model reset` — вернуть `LLM_MODEL` из `.env`. Выбор действует сразу, без перезапуска
- ссылка на профиль (`tiktok.com/@name`, `instagram.com/name`) — разбор аккаунта
- ссылка на ролик (`tiktok.com/@name/video/…`, `vm.tiktok.com/…`, `instagram.com/reel/…`) — разбор ролика
- `@name` — бот спросит, TikTok это или Instagram

## Настройки

Все настройки — в `.env`, описание в [.env.example](.env.example). Главные:

- `TOPICS`, `FEED_DAYS`, `FEED_SIZE`, `FEED_MIN_VIEWS` — что и как искать в подборке;
- `DIGEST_TIME` — время ежедневной подборки (пусто — выключено; приходит, только если бот в это время запущен);
- `PROFILE_VIDEOS`, `PROFILE_POPULAR`, `ANALYZE_TOP` — сколько последних и сколько самых популярных за всё
  время роликов собирать с аккаунта и сколько разбирать подробно. По умолчанию разбираются 3 свежих хита
  (×2 к медиане последних роликов и выше) и 2 лучших ролика за всё время; в конце PDF — таблица всех собранных
  роликов, чтобы было видно, из чего выбирал бот;
- `LLM_MODEL`, `LLM_REASONING_EFFORT` — модель и глубина разбора; модель должна понимать картинки;
- `TRANSCRIBE_MODEL` — модель расшифровки речи.

## Видео целиком

Обычно нейросеть получает 6 кадров ролика и расшифровку речи. Модели, которые умеют видео
(например, `google/gemini-3.8-flash`), в режиме «видео целиком» получают сам ролик со звуком —
бот сжимает его до 480p и первых 90 секунд. Так модель видит темп, монтаж, движение и слышит голос.
Это примерно вдвое дороже по нейросети, но всё равно дешевле Apify.

Режим включён по умолчанию (`LLM_VIDEO_MODE=auto`) и выключается кнопкой в `/model`.
Если Polza не примет видео для модели, бот сам переделает разбор по кадрам и напишет об этом
под результатом.

## Расшифровка речи

- **TikTok** — берутся автоматические субтитры TikTok (бесплатно), если они есть у ролика.
- **Reels и ролики TikTok без субтитров** — бот вырезает звук через ffmpeg и отправляет его в Polza на
  распознавание (`TRANSCRIBE_MODEL`, по умолчанию `openai/gpt-4o-mini-transcribe`, ~0,35 ₽ за минуту).

## Что сколько стоит

После каждой операции бот пишет, во что она обошлась: `💸 Apify ≈ $0.08 · нейросеть ≈ 2.1 ₽ (openai/gpt-6.1-terra)`,
а перед подборкой — её оценку.

**Apify** берёт плату за каждый собранный ролик (цены из консоли Apify, октябрь 2026):

| Что | Цена |
| --- | --- |
| ролик TikTok (`clockworks/tiktok-scraper`) | $0.0037 + $0.001 за запуск |
| ролик Reels по хэштегу (`apify/instagram-hashtag-scraper`) | $0.0026 |
| скачивание видео TikTok через Apify (только если yt-dlp не справился) | $0.0013 |

Сколько выходит:

| Операция | Apify |
| --- | --- |
| подборка: 4 темы × 10 роликов × TikTok и Reels (по умолчанию) | ≈ $0.25 |
| подборка: 6 тем × 30 роликов × 2 площадки | ≈ $1.14 |
| разбор аккаунта TikTok: 30 последних + 5 самых популярных роликов | ≈ $0.13 |
| повторный разбор того же аккаунта в течение 24 ч | $0 (кэш) |
| разбор одного ролика TikTok по ссылке | $0 (yt-dlp) |

Бесплатный план Apify — $5 в месяц. Главный расход — подборка: платятся **все** собранные ролики,
в том числе старые, которые потом отсеются по `FEED_DAYS` (бот пишет, сколько было свежих).
Как удешевить: меньше тем (`/topics`), меньше `FEED_RESULTS_PER_TOPIC`, одна площадка в `FEED_PLATFORMS`.
Ежедневная подборка (`DIGEST_TIME`) по умолчанию выключена: каждый день — это стоимость одной подборки.
`APIFY_MAX_CHARGE_USD` (по умолчанию $0.5) — потолок одного запуска.

**Polza** — зависит от модели. `openai/gpt-6.1-terra` примерно втрое дешевле `anthropic/claude-sonnet-5.5`;
разбор аккаунта на ней — порядка нескольких рублей. Расшифровка речи — меньше рубля на разбор.

Видео TikTok бот скачивает бесплатно через yt-dlp. Если TikTok перестал скачиваться, обновите yt-dlp:
запустите `setup.bat` / `./setup.sh` ещё раз (пока он не обновлён, бот докачивает через Apify за $0.005 за ролик).

## Как устроено

```
bot/
  __main__.py      запуск, ежедневная подборка
  handlers.py      команды, кнопки, ссылки (aiogram 3)
  service.py       сценарии: подборка, разбор аккаунта, разбор ролика
  apify_source.py  запуски акторов Apify
  models.py        единый формат ролика для TikTok и Instagram
  metrics.py       ранжирование подборки, поиск залетевших роликов
  media.py         скачивание видео, кадры и звук (ffmpeg), субтитры
  llm.py           клиент Polza.ai (OpenAI-совместимый API): чат и распознавание речи
  analyzer.py      разбор роликов нейросетью (ответ в JSON)
  formatting.py    тексты сообщений
  storage.py       SQLite: присланные ролики, кэш, темы
```

Если какой-то актор Apify поменяет формат входа, поля можно дополнить без правки кода через
`APIFY_*_EXTRA_INPUT` (JSON), а сам актор заменить через `APIFY_*_ACTOR`.
